# The settings audition — 19 Aug 2026

Fifteen files: three characters, five settings each. Same line every time, same
seed, same reference clip. **Only two numbers move**, so a difference you hear
is a difference one of them caused.

| Name | Acting | Pace |
|---|---|---|
| `house` | 1.5 | 1.0 — what everything has used so far |
| `bigger` | 2.2 | 0.95 |
| `flat` | 0.8 | 1.0 |
| `faster` | 1.5 | 0.85 |
| `slower` | 1.5 | 1.15 |

## What to listen for

**First: does `bigger` actually act more than `house`?** If it does, Τσίκα and
Καίτη want it and Σερίφης probably does not. If the two sound the same, the
acting dial is not doing what its name says and the character has to come from
the writing instead.

**Second: is `flat` usable?** It is the safety net. If a lesson ever needs a
line said straight — a warning, a vet fact — this is what that sounds like.

**Third: `faster` against `slower`.** Already measured, before you listen:

| | house | faster | slower |
|---|---|---|---|
| Καίτη | 12s | 10s | 14s |
| Σερίφης | 9s | 8s | 10s |
| Τσίκα | 8s | 7s | 9s |

Same words. So **pace is a real control** — a 40% spread on Καίτη — and the
question is only whether `faster` still sounds like a person rather than a
recording played too quickly.

## What to say back

One line per character: which setting, and anything that is wrong with all of
them. "Καίτη bigger, Σερίφης house, Τσίκα faster" is a complete answer.

Nothing else about voices can be settled until this is.
